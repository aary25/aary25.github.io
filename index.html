Featured project

Self-Hosted DevOps Home Lab

Built a Proxmox VE 8 server on a Dell OptiPlex, running Debian 13 VMs and a Docker stack: Gitea with Woodpecker CI, Prometheus + Grafana monitoring, Nginx Proxy Manager with automatic TLS, and Pi-hole. Every Compose stack deploys from Git on push through path-filtered pipelines. Hardened with UFW, Fail2ban, and key-only SSH, codified as Ansible roles; since the ISP's CG-NAT rules out port forwarding, remote admin runs over a Tailscale (WireGuard) mesh.
