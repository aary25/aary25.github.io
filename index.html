001 — Featured

Self-Hosted DevOps Home Lab

Built a Proxmox VE 8 server on a Dell OptiPlex, running Debian 13 VMs and a Docker stack: Gitea with Woodpecker CI pipelines, Prometheus + Grafana monitoring, and Nginx Proxy Manager with automatic TLS. Hardened with UFW, Fail2ban, and key-only SSH; since the ISP's CG-NAT rules out port forwarding, remote admin runs over a Tailscale (WireGuard) mesh.

002

FPGA Digital Logic Lab Suite

Designed and simulated a series of digital circuits on an FPGA using Verilog HDL. Work includes synchronous counters, JK flip-flop behavioral models, 7-segment decoders, LFSR sequences, SR/D latches, ring oscillators, and static hazard analysis. Verified all designs using Vivado waveform simulation.
